# Security policy

## Supported versions

Security fixes are applied to the latest supported release line.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report security issues privately through the GitHub repository's security reporting functionality when available, or contact Codegenie through https://www.codegenie.be.

Include the affected version, reproduction steps, impact and any proposed mitigation. Do not include production credentials, customer data or other secrets.
